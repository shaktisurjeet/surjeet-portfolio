# Surjeet Singh Portfolio

A responsive single-page portfolio for a NOC / Networking / Cloud / DevOps profile.

## Files

- `index.html` — website content
- `style.css` — responsive dark tech design
- `script.js` — mobile navigation and reveal animations
- `resume.pdf` — add your own resume here

## Before publishing

Search and replace these placeholders in `index.html`:

- `your-email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- `github.com/your-username`
- project GitHub URLs

Also replace the certification placeholders with your exact certificates.

## GitHub Pages

1. Create a GitHub repository named `surjeet-portfolio` (or `YOURUSERNAME.github.io`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and your `resume.pdf`.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your public portfolio URL.

For a custom domain, buy a domain such as `surjeetsingh.dev` and configure it in GitHub Pages later.
